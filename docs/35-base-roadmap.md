# Base Roadmap & Milestones

## Completed
- **Aug 2023** — Base mainnet launch
- **Oct 2023** — Fault proof system deployed
- **Mar 2024** — EIP-4844 blobs (gas cost -10x)
- **Jun 2024** — Stage 1 decentralization (permissioned fault proofs)
- **2024** — Basenames launch
- **2024** — Smart Wallet GA

## In Progress / Planned
- **Stage 2** — Full decentralization (permissionless fault proofs, no Security Council veto)
- **Based rollup** — Sequencer decentralization (L1 validators sequence L2 txs)
- **Interoperability** — Native cross-chain composability (OP Stack Superchain)
- **EIP-7702** — EOA smart account upgrades

## Superchain Vision
Base, Optimism, Mode, Zora, and other OP Stack chains forming an interoperable Superchain:
- Shared liquidity
- Cross-chain native messages without bridges
- Shared sequencing (roadmap item)
