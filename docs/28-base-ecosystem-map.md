# Base Ecosystem Map

- **RPC**: Alchemy, QuickNode, Infura, Ankr, public (mainnet.base.org)
- **Indexing**: The Graph, Envio, Ponder, Goldsky
- **Oracles**: Chainlink, Pyth, Redstone, API3
- **Bridges**: Official Bridge, Across, Stargate, Relay, Synapse

- **Lending**: Aave v3, Morpho, Compound v3, Euler
- **Stablecoins**: USDC (native), DAI, crvUSD
- **Perps**: Synthetix, dYdX (v4 coming), Kwenta
