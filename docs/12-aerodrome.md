# Aerodrome Finance

Aerodrome is the central liquidity hub on Base, using the ve(3,3) tokenomics model.

## Tokens
- **AERO** — governance and reward token
- **veAERO** — vote-escrowed AERO (locked for up to 4 years)

## Core Concepts
- **Pools**: Volatile (CLAMM) and Stable (xy=k)
- **Gauges**: Liquidity incentive distribution
- **Bribes**: External incentives for veAERO voters
- **Emissions**: Weekly AERO emissions directed by veAERO votes
