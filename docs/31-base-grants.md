# Base Grants & Ecosystem Funding

## Base Ecosystem Fund
Coinbase Ventures + Base team invest in projects building on Base.

## Builder Programs
- **Base Builds**: Hackathon series, run periodically
- **Base Camp**: Developer education and grants
- **Onchain Summer**: Annual consumer app campaign with prizes

## How to Apply
1. Build a meaningful product on Base
2. Apply at https://base.org/ecosystem-grants
3. Focus areas: DeFi, consumer apps, infrastructure, developer tools

## Other Funding Sources
- **Optimism RetroPGF** — Base contributes to Optimism's retroactive public goods funding
- **Coinbase Ventures** — direct investment for larger projects
- **ETHGlobal** — Base is a common sponsor at hackathons

## Tips
- Open-source code preferred
- Clear onchain usage metrics
- Community engagement on Farcaster / X
