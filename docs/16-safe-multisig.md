# Safe Multisig on Base

## Deploy a Safe
1. Go to https://app.safe.global
2. Select Base network
3. Set owners and threshold
4. Deploy (sponsored on Base)

## Key Addresses
- SafeProxyFactory: `0x4e1DCf7AD4e460CfD30791CCC4F9c8a4f820ec67`
- SafeL2: `0x29fcB43b46531BcA003ddC8FCB67FFE91900C762`

## Modules & Guards
- Zodiac modules for governance integration
- SpendingLimit module for daily limits
- Delay module for timelocked execution

## Safe SDK
```bash
npm install @safe-global/protocol-kit
```
