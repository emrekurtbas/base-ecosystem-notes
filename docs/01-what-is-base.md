# What is Base?

Base is a secure, low-cost, developer-friendly Ethereum L2 built by Coinbase on the OP Stack.

## Key Facts
- Launched: August 2023 (mainnet)
- Chain ID: 8453
- Native token: ETH (no separate gas token)
- Block time: ~2 seconds
- Avg gas cost: ~$0.001–0.01 per tx

## Why Base?
- Backed by Coinbase (200M+ verified users)
- EVM-equivalent — all Ethereum tooling works
- Fast finality, low fees
- Growing ecosystem: DeFi, NFTs, SocialFi
